Kunden-Feedback

Kunden melden sich auf ihrer Website an und tragen Wünsche direkt zur jeweiligen Seite ein. Alles erscheint live im Portal – auf Wunsch setzt der Wächter die Änderungen automatisch mit Claude um.

Ausprobieren

Unten rechts auf „KI-Wunsch“ klicken. Im Demo-Modus funktioniert jede E-Mail-Adresse; mit „agentur“ in der Adresse meldest du dich als Agentur an. Die Daten bleiben nur in diesem Browser.

Einbinden

Eine Zeile vor </body> auf jeder Seite der Kunden-Website:

<script src="https://michele4800.github.io/kunden-feedback/feedback.js" data-projekt="kunden-slug" defer></script>
